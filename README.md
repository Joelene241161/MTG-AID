## About the Project
<!-- header image of project -->
![image1][image1]

### Project Description

MTG AID is a data driven web application that compares data in charts. Magic: The Gathering is a trading card game and all of my data came from an API that has information on the cards and sets.

### Built With

* [Chart.js](https://www.chartjs.org/docs/latest/getting-started/)
* [MTG API](https://docs.magicthegathering.io/)

## Features and Functionality


### Home page

Users can see learn what type of data a card contains and what each data point means in the contet of the game.

![Account][image2]

### Compare cards

Users can compare two random Magic: The Gathering cards. The data is compared in charts, and the selected cards can be changed for a different random card.
